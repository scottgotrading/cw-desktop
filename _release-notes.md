First public alpha of ChartsWatcher Desktop Edition for Windows.

## Install
1. Download `SCOTTGO-CW-Desktop-Setup-2.0.0-alpha.exe` below.
2. Run it. If Windows shows a blue "protected your PC" warning, click **More info** then **Run anyway** (expected for a new app; clears as more people install it).
3. The attached Install Guide PDF has a full walkthrough.

Requires your own ChartsWatcher account. ChartsWatcher integration used with permission.
